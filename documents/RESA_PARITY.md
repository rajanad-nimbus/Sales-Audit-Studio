# ReSA 15.0.1 workflow parity

This map translates the supplied [Oracle Retail Sales Audit User Guide, Release 15.0.1](resa-1501-ug.pdf), into reviewable ZeTSA capabilities. “Covered” means a corresponding workflow is present in the current code; it does not claim production integration or complete end-to-end validation. The guide describes the reference workflow, while ZeTSA keeps external identity, immutable audit history, and independent financial approvals as platform controls.
